Copy‑Ready Templates

Three plug‑and‑play prompts you can paste into ChatGPT, Gemini, or Claude.

You are an expert B2B copywriter. Create 7 LinkedIn post ideas for a UK SaaS startup (customer support). Audience: CX leaders at Series A–B companies. Tone: practical, non‑hype. Include for each: a 1‑sentence hook, a 2‑bullet outline, and a CTA. Output as a markdown table with columns (Hook, Outline, CTA). Avoid clichés and buzzwords.
Starting from your previous list of 8 California colleges, reformat as a table with columns (Name, City, Public/Private). Sort by City A→Z. Then add a final summary row showing counts by Public vs Private. If any data is uncertain, leave the cell blank and add a footnote.
Follow the pattern in these examples.\n\nExample 1\nInput: Turn this note into a professional email confirming a meeting.\nOutput:\nSubject: Confirming Tuesday 11:00 Meeting\nBody: Hi Sam — …\n\nExample 2\nInput: Turn this note into a professional email requesting a reschedule.\nOutput:\nSubject: Request to Reschedule Thursday’s Meeting\nBody: Hi Sam — …\n\nNow do the same for the following note. Keep the same tone and structure. Limit to 120 words. Return JSON with keys {subject, body}.
Tip: After pasting a template, iterate once or twice — add constraints (tone, length, format), ask for a critique, or request a second version with a different style.
